# La saga · Armin Vandik

Mini reproductor para celular (iOS y Android) con la saga completa: *Lo que nunca dije*, *Brotes*, *Todavía nos amamos* y el bonus track *Mediodía*.

Un solo archivo (`index.html`), sin dependencias que instalar. Los videos se reproducen desde YouTube.
